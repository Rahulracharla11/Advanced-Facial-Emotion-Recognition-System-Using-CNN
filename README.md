# Advanced-Facial-Emotion-Recognition-System-Using-CNN

## Description
This project is an advanced facial emotion recognition system that uses a Convolutional Neural Network (CNN) to detect human emotions from images. The model can identify 7 different emotions: angry, sad, disgust, fear, happy, surprise, and neutral.

## Key Features
Deep Learning Model: Uses a CNN architecture with multiple convolutional layers, leaky ReLU activation, and batch normalization for accurate emotion detection.

Data Processing: Includes image resizing, normalization, and noise addition to improve model robustness.

Performance Metrics: Achieves high accuracy with detailed evaluation through confusion matrices and classification reports.

Visualization: Provides clear plots of training accuracy/loss and sample predictions with true vs predicted labels.

## How It Works
The system takes facial images as input (64x64 pixels)

Processes the images through the trained CNN model

Outputs the predicted emotion with confidence

## Applications
This technology can be used in:

Mental health monitoring systems

Human-computer interaction

Customer sentiment analysis

Security systems

Educational tools

The model is saved as 'model_emotion_recogn.h5' and can be easily integrated into other applications.
